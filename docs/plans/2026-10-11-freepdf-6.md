# FreePDF 6.0 implementation and acceptance plan

**Goal:** Release a complete desktop UI refresh, a Windows PDF reader without WebEngine dependency, direct log export in About, the latest released PDFMathTranslate engine, and elegant local/side-by-side PDF exports.

**Architecture:** A native Qt PDF reader runs on Windows; the Mac PDF.js reader automatically switches to it when loading fails. Shared desktop tokens and vector icons cover the main workspace, settings and export sheets. A worker creates vector page pairs in an atomic output file; upstream translation runs on a disposable copy, keeping the user's original and translated output intact. Developer ID signs the local Mac build; notarization stays disabled per the user's request.

**Tech stack:** PyQt6, QtPdf, PDF.js, PyMuPDF, pdf2zh 1.9.11 (latest GitHub/PyPI release verified 2026-10-11), PyInstaller, NSIS and GitHub Releases.

1. Windows: do not import or package QtWebEngine components. Assert native libraries/icon, test real rendering from a clean PATH and unrelated working directory, and repeat after NSIS installation into a path containing spaces.
2. PDF reader: real visible page pixels, continuous pages, navigation, dual-pane scroll/zoom, special filenames, repeated imports, invalid PDFs, automatic browser-to-native recovery and bounded native rendering.
3. Design: preserve the original app icon and toolbar/panel arrangement per the user’s correction; no in-content logo/header; consistent line action icons, larger body/caption fonts, keyboard focus and disabled states, spacing and backgrounds across the workspace and dialogs. Inspect real screenshots of the main window, About, engine settings, translation settings, batch and export.
4. Logs: remove the diagnostics/settings entry and intermediate dialog. About's bottom-left row contains Export logs beside Check updates; one save action exports the support ZIP and displays inline feedback. No document/API config is included.
5. Translation: lock pdf2zh 1.9.11; exercise the real ONNX/upstream PDF transformation with only the remote translation replaced by a deterministic local response. Verify original bytes survive, Chinese translated text is written to local PDF and output remains exportable.
6. Export: toolbar button enabled once a local translation exists; default wide PDF pairs source/translation on each page with searchable vector text. Also offer translated-only export. Verify mixed page sizes, rotated/empty pages, page count mismatch, original/translation overwrite protection, atomic failure and UI worker behavior. Optional automatic dual output now uses left/right pairs.
7. Release: finish macOS/Windows regression and actual frozen/installed app checks; build/sign/validate Mac ARM64 app and DMG locally. Publish v6.0.0 with changelog, both installers and hashes from the exact tested source. Audit all requirements before completing the active goal.
