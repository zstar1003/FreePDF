# FreePDF v5.1.3

本次更新重点修复 PDF 预览加载隐患，并增加完整的本地诊断日志，便于定位“能翻译但界面空白”等问题。

## 修复

- 修正 Windows 安装包内 PDF.js 的资源目录，增加关键预览资源的完整性检查，并兼容旧目录布局。
- 修复文件名包含中文、空格、`&`、`#`、`%`、`+` 等字符时可能无法加载预览的问题。
- 修正预览控件的渲染设置应用位置及 WebEngine 资源清理流程。
- 修复翻译日志对象的初始化问题，并修正翻译完成时的文件缺失检查。
- 翻译成功后仍会保留预览异常提示，避免把翻译成功误当成页面显示成功。

## 新增诊断与日志

- 在 **引擎配置 → 诊断与日志** 中提供 **导出日志** 和 **查看翻译日志**，移除主界面的日志按钮。
- 启动后自动记录运行环境、文件访问、PDF.js 资源检查、文档加载、首个页面渲染、JavaScript 错误、预览超时、渲染进程退出及翻译流程。
- 导出 ZIP 包含系统与组件版本、原文/译文预览状态及近期日志，不附带 PDF 或 API 配置文件；常见密钥字段和已登记的密钥值会脱敏。
- 日志采用容量限制及轮转保存，翻译界面的清空操作不会删除诊断历史。
- 新增 **使用软件渲染** 选项，更改后重启生效，可用于排查显卡驱动兼容问题。

## 安装与反馈

- Windows：下载 `FreePDF_v5.1.3.exe`。
- macOS Apple Silicon（arm64）：下载 `FreePDF_v5.1.3_macOS.dmg`。Mac 应用和 DMG 使用 Developer ID 签名，本次未进行 Apple 公证。
- 出现预览空白时，请先重现问题，等待约 30–35 秒，再通过 **引擎配置 → 诊断与日志 → 导出日志** 提供诊断包。

上述预览隐患已修复，但个别设备的具体故障仍需结合日志分析。[详细排查说明](https://github.com/zstar1003/FreePDF/blob/v5.1.3/docs/windows-preview-diagnostics.md)。
