# FreePDF v6.0.0

本次大版本重点解决 Windows PDF 预览空白和 WebEngine DLL 报错，并完善阅读界面、日志入口与 PDF 导出体验。

## PDF 预览与稳定性

- Windows 使用内置 Qt PDF 阅读器，不再启动 QtWebEngineProcess，也不再依赖 Qt6WebEngineCore.dll。支持连续阅读、页面跳转、双栏滚动同步与 Ctrl+滚轮缩放，无需用户调整 DLL、环境变量或软件渲染设置。
- Mac 保留 PDF.js 预览；预览失败时自动切换到内置阅读器。
- 修复安装包的 UI 资源目录和图标读取路径，软件从快捷方式或其他工作目录启动时，窗口图标仍可正确显示。
- Windows 原生阅读器提供阅读、导航、缩放与导出；PDF.js 的网页绘图批注工具不在该阅读器中提供。

## 界面与日志

- 保留原有软件图标、顶部工具栏顺序及原文/译文/问答三栏布局，不增加页面内的品牌图标或标题区。
- 统一操作按钮的线条图标、字号、间距、输入框、焦点与禁用状态，增大提示文字，提高可读性。
- 移除引擎配置内的“诊断与日志”入口及中间弹窗。在 **关于软件** 底部左侧，**导出日志** 与 **检查更新** 并排显示；选择保存位置即可导出 ZIP，结果直接显示在窗口内。
- 日志继续自动记录运行环境、实际阅读器、文档加载、首个页面渲染、异常与翻译/导出过程；导出不附带 PDF 或 API 配置文件，密钥脱敏，日志保留容量限制。

## 翻译与 PDF 导出

- 将指定项目 PDFMathTranslate 的依赖从 pdf2zh 1.9.10 升级至 **1.9.11**，这是发布时 GitHub 与 PyPI 上的最新正式版本。
- 修正译文字体参数，保留上游默认的公式字体识别规则。
- 翻译完成后，本地译文继续保留。顶部新增 **导出 PDF**：默认生成 **左右对照版**，每页左侧原文、右侧对应译文，也可选择只导出译文。
- 对照 PDF 保留可搜索的文字与矢量内容；支持不同页面尺寸、旋转页和空白页，导出过程在后台完成。
- 勾选自动保留双语文件时，生成的 dual.pdf 也改为逐页左右对照。
- 导出采用临时文件完成后替换，失败时保留已有目标文件；禁止覆盖原文和本地译文。原文与译文页数不匹配时提供明确提示。
- 翻译引擎只处理软件创建的副本，避免新版上游临时文件清理逻辑误删从系统临时目录打开的原文。

## 安装

- Windows：`FreePDF_v6.0.0.exe`，64 位安装包。
- macOS Apple Silicon：`FreePDF_v6.0.0_macOS.dmg`，使用开发者本机 Developer ID 签名。本次按要求未进行 Apple 公证。
- `SHA256SUMS.txt` 提供安装包校验值。
