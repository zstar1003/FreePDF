## 安装包选择

- **Windows 标准版：`FreePDF_v6.0.1.exe`**。默认使用 PDF.js，推荐通常使用此版本。
- **Windows 原生预览特别版：`FreePDF_v6.0.1_Windows_Native.exe`**。使用内置 Qt PDF，安装包不含 WebEngine，适合曾遇到 Qt6WebEngineCore.dll 缺失或空白预览的 Windows 电脑。安装名称为 FreePDF Native，可与标准版共存。
- **macOS ARM64：`FreePDF_v6.0.1_macOS.dmg`**。默认使用 PDF.js，使用本机 Developer ID 签名；按要求未进行 Apple 公证。

原生版源码分支：[codex/windows-native-v6.0.1](https://github.com/zstar1003/FreePDF/tree/codex/windows-native-v6.0.1)。两个 Windows 版本均提供翻译、问答、导出和日志；原生阅读工具以翻页、缩放和适宽为主。标准版预览失败时也会尝试原生恢复。

## 更新内容

- 恢复 PDF.js 为标准版默认渲染器；补齐 Windows WebEngine 子进程的本地 VC 运行库和 DLL/资源加载路径。
- 翻译改为逐页保存、逐页显示。超时、服务异常或手动停止后，已完成的译文仍可阅读和导出，后续页面暂时保留原文。
- 新增断点续译：点击进度详情里的“继续翻译”，或重新导入同一 PDF，在源文件和翻译配置一致时跳过已完成页。
- 左下角状态、进度条和百分比支持点击打开小型详情窗口，显示真实步骤、页码、已保存页数、段落处理、耗时和等待时间。
- 改进 120 秒无响应判断：依据翻译服务实际返回情况判断，不再仅靠百分比变化；移除固定十分钟整份文档超时，限制段落错误重试。停止独立翻译进程时保留已保存页面。
- 统一界面字体、按钮样式，居中调整“关于软件”的说明、版本、作者信息和链接；保留原窗口图标、原工具栏和三栏布局。
- 延续左右对照/仅译文导出、脱敏日志导出以及浏览器预览异常时的原生恢复。

## 部分译文说明

部分结果保存为原 PDF 同目录下的 `文件名-partial-mono.pdf`，断点保存为 `文件名-partial.freepdf.json`。部分 PDF 保持完整页数，未完成页保留原文；详情窗口显示已完成页数。翻译成功后生成 `文件名-mono.pdf` 并清理断点。启用左右对照保存时生成 `文件名-dual.pdf`。

API 无响应发生时，尚未完成的当前页需要继续翻译；已经保存的页面不会丢失。该版本不提供单页内半个段落的 PDF 排版结果。

校验文件：`SHA256SUMS.txt`。
