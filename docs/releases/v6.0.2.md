## 安装包选择

| 安装包 | 适用情况 |
| --- | --- |
| `FreePDF_v6.0.2.exe` | Windows PDF.js 标准版，默认推荐，保留 PDF.js 阅读工具。 |
| `FreePDF_v6.0.2_Windows_Native.exe` | Windows 原生预览特别版，使用内置 Qt PDF，不包含 WebEngine。曾遇到 Qt6WebEngineCore.dll 缺失或空白预览的电脑可直接安装此版本；安装为 FreePDF Native，可与标准版共存。 |
| `FreePDF_v6.0.2_macOS.dmg` | Apple Silicon / ARM64 Mac，使用 PDF.js，已签名并公证。 |

原生版源码分支：[codex/windows-native-v6.0.2](https://github.com/zstar1003/FreePDF/tree/codex/windows-native-v6.0.2)。两个 Windows 版本均支持翻译、问答、导出和日志；原生阅读器提供翻页、缩放、适宽等功能。主分支默认使用 PDF.js，标准版预览失败时也会尝试原生恢复。

点击左下角状态、进度条或百分比即可查看真实翻译步骤。已完成页面会立即保存，未完成页面暂时保留原文；超时、失败或停止后可阅读、导出并继续翻译已保存的部分结果。当前页尚未完成的段落需继续处理。

安装包校验文件：`SHA256SUMS.txt`。README 已更新版本选择与使用说明；网盘和 Homebrew 可能稍晚更新。
